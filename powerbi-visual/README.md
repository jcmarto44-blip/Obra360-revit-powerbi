   # powerbi-visual
   
   El visual custom de Power BI: Obra360Pulse.
   
   Construido con pbiviz + TypeScript + Three.js. Sustituye al
   visualizador de Speckle: lee los datos desde Supabase (vía la
   consulta de Power BI) y renderiza el modelo 3D completo dentro
   del dashboard, con interacción cruzada (cross-filtering).
